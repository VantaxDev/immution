## Problem

### You probably do not need an enterprise WAF.

Small Apache servers still receive constant probing, but many owners need
something narrower than a CDN security platform and more explainable than a
collection of isolated bans.

## How it works

1. Read Apache access logs locally.
2. Score documented error and probe patterns.
3. Record what would be blocked in monitor mode.
4. Enable temporary blocking only after reviewing the workload.
5. Explain every decision from local state.

## Trust section

- no direct trust in client-controlled forwarding headers;
- unprivileged daemon and restricted runtime permissions;
- atomic state updates and immediate unblock command;
- public scoring rules, threat model and security policy.

## Final call to action

Start in monitor mode. See what Immution would block before it blocks anything.
